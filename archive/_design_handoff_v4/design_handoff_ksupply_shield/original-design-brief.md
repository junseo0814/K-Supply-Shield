# K-Supply Shield — FTA 디자인 융합 Claude 프롬프트

> FTA 강국, KOREA (https://fta.motir.go.kr) 디자인 시스템을  
> K-Supply Shield 핵심광물 공급망 관리 플랫폼에 적용한 통합 프롬프트  
> 대상 도구: 충격 시뮬레이터 / 비축·조달 의사결정 도구 / 시나리오 비교

## 디자인 원칙: FTA → K-Supply Shield 번역 규칙

| FTA 사이트 요소 | K-Supply Shield 적용 방식 |
|---|---|
| 네이비 #1B2556 — 권위·신뢰 | 플랫폼 전체 Primary (헤더, 사이드바, CTA) |
| 살구핑크 #FFCDCD — 포인트 | 위험 경고, 임계치 초과 알림 색상으로 전환 |
| 블루 #007AFF — 보조 강조 | 정보 링크, 보조 지표, 진행 상태 |
| 직각 border-radius 0px | 대시보드 패널, 카드, 버튼 전체 유지 |
| 플랫 / 그림자 없음 | 차트·테이블·패널 모두 flat 처리 |
| Pretendard / 13–16px | 데이터 레이블, 수치, 설명 텍스트 동일 적용 |
| 정보 밀도 높음 | 다중 KPI 동시 표시, 컴팩트 레이아웃 유지 |

## [프롬프트 1] 충격 시뮬레이터 (Supply Shock Simulator)

```
K-Supply Shield의 "충격 시뮬레이터" 페이지를 구현해줘.
한국 산업통상자원부 FTA 포털의 디자인 시스템을 기반으로 한다.

=== 디자인 시스템 (FTA 기반) ===
Font: Noto Sans KR (Google Fonts import)
Primary: #1B2556 (네이비)
Accent: #007AFF (블루)
Background: #F1F2F3
Card: #FFFFFF, border 1px #DDDDDD, radius 0px
Button: radius 0px, shadow none
위험색: #C0392B(위험) / #E67E22(경계) / #27AE60(안전) / #FFCDCD(주의)

=== 페이지 레이아웃 ===

[헤더 바]
- 배경 #1B2556, 높이 56px
- "⚡ 충격 시뮬레이터" 흰색 bold 좌측
- 우측: 마지막 시뮬레이션 시각 + "시뮬레이션 초기화" 버튼(ghost)

[3단 컬럼 레이아웃 — 왼쪽 입력 | 중앙 결과 | 우측 인사이트]

--- 왼쪽 패널 (입력, 300px 고정) ---
카드 제목: "충격 시나리오 설정" (좌측 4px #1B2556 보더)

① 광물 선택
  - 드롭다운: 리튬 / 코발트 / 니켈 / 희토류 / 구리 / 전체
  - 선택된 광물 뱃지: #1B2556 bg, 흰 텍스트

② 충격 유형 선택 (라디오 버튼 그룹)
  - 수출 규제 (중국/콩고 등 주요국)
  - 물류 차단 (항만 봉쇄, 운임 급등)
  - 자연재해 (광산 사고, 기후)
  - 지정학적 분쟁
  - 복합 충격

③ 충격 강도 슬라이더
  - 라벨: "공급 감소율"
  - 범위: 0% ~ 100%
  - 슬라이더 트랙: #1B2556
  - 썸: 흰색 원, 2px border #1B2556
  - 현재값 표시: 우측 숫자 (bold 20px #1B2556)
  - 25% 이하 → 텍스트 "경계", 50% 초과 → "심각", 75% 초과 → "위험"

④ 충격 지속 기간
  - 선택 버튼 그룹: [1개월] [3개월] [6개월] [12개월] [24개월]
  - 선택 시: #1B2556 bg + 흰 텍스트, 미선택: #F1F2F3 + #333

⑤ 대상 국가/지역
  - 체크박스 멀티 선택 목록
  - 중국 / 콩고 / 칠레 / 호주 / 필리핀 / 인도네시아 / 기타
  - 체크 시: #1B2556 체크박스

[실행 버튼]
  "▶ 시뮬레이션 실행"
  - bg #1B2556, 흰색 bold, 전체 너비, h 44px, radius 0
  - 실행 중: "분석 중..." + 스피너 (흰색 선형)

--- 중앙 패널 (메인 결과, flex-grow) ---

① KPI 요약 카드 4개 (2×2 그리드)
  각 카드: 흰 배경, 1px #DDDDDD 보더, radius 0
  - 예상 공급 충격률: 숫자 큰 폰트 (36px bold #C0392B), 단위 "%"
  - 영향 기간: 숫자 + "개월" 표기
  - 국내 비축 여유: 숫자 + "일분" / 안전 기준 대비 색상 변화
  - 긴급 조달 필요량: 숫자 + "톤"

② 시계열 충격 파급 차트 (Line/Area Chart)
  - 카드 제목: "공급량 변화 예측 (시뮬레이션)" + 좌측 4px #1B2556 보더
  - X축: 월 (충격 발생 전 3개월 ~ 충격 후 24개월)
  - Y축: 공급량 (기준치 대비 %)
  - 선 1: 정상 공급선 (점선 #007AFF)
  - 선 2: 충격 시나리오 (실선 #C0392B, area fill rgba(192,57,43,0.1))
  - 안전 임계선: 점선 수평선 #E67E22 + 레이블 "안전 기준선 (60%)"
  - 충격 발생 시점: 수직 점선 #1B2556 + "충격 시작" 레이블

③ 국가별 영향도 히트맵 테이블
  - 열: 광물 | 수입 의존도 | 충격 전 | 충격 후 | 변화율 | 위험도
  - 위험도 셀: 색상 배경 (안전 → 위험 그라데이션)
  - 테이블 헤더: #1B2556 bg + 흰 텍스트
  - 홀수 행: #F8F9FA

④ 파급 경로 시각화
  - 카드 제목: "공급망 파급 경로"
  - 노드-링크 다이어그램 (SVG)
  - 원산지 → 항만 → 중간재 → 국내 산업 → 최종재
  - 충격받은 노드: 빨간 외곽선 + 진동 애니메이션 효과
  - 정상 노드: #1B2556 채우기
  - 링크: 굵기 = 의존도 비례

--- 우측 패널 (인사이트, 280px 고정) ---

① 위험 경보 박스
  - 위험 수준별 색상: critical → #C0392B bg, 흰 텍스트
  - "즉각 조치 필요" / "모니터링 강화" / "정상" 텍스트
  - 좌측 4px 보더 강조

② 권고 조치 리스트
  - 번호 리스트, 각 항목: 아이콘 + 설명 텍스트 (13px)
  - 우선순위: [긴급] 뱃지(#C0392B) / [권고] 뱃지(#007AFF)

③ 비교 기준 요약
  - 현재 비축량 vs 목표 비축량 진행바
  - 바 색상: 달성률에 따라 #27AE60 → #E67E22 → #C0392B

④ "시나리오로 저장" 버튼
  - Ghost 버튼, border #1B2556, radius 0

=== 인터랙션 ===
- 슬라이더 조작 시 KPI 카드 실시간 업데이트 (transition 300ms)
- 충격 강도 75% 초과 시 헤더 바가 #C0392B로 flash 1회
- 차트 호버: 툴팁 (흰 bg, 1px #DDD border, 내용: 날짜 + 수치)
- 모든 transition: ease 200–300ms

=== 기술 스펙 ===
단일 HTML 파일, Chart.js CDN 사용, 한국어 텍스트
샘플 데이터로 차트 구현 (실제 API 연동 가능하도록 함수 분리)
```

## [프롬프트 2] 비축·조달 의사결정 도구 (Procurement Decision Tool)

```
K-Supply Shield의 "비축·조달 의사결정 도구" 페이지를 구현해줘.
FTA 강국, KOREA 사이트의 디자인 언어(#1B2556 네이비, 직각, 플랫)를 그대로 적용한다.

=== 디자인 시스템 (동일 적용) ===
Font: Noto Sans KR
Primary: #1B2556 | Background: #F1F2F3 | Card: #FFFFFF 0px radius
위험색 체계: #C0392B / #E67E22 / #F39C12 / #FFCDCD / #27AE60
버튼: radius 0, shadow none

=== 페이지 구조 ===

[헤더]
"🏗 비축·조달 의사결정 도구" — 배경 #1B2556, 흰색

[탭 네비게이션] (FTA 사이트 탭 스타일 그대로)
[비축 현황] [조달 시뮬레이션] [의사결정 매트릭스] [이력 관리]
활성탭: 하단 3px solid #1B2556, 텍스트 #1B2556

=== 탭 1: 비축 현황 ===

① 광물별 비축 상태 카드 그리드 (3열)
  각 카드 구성:
  - 상단 컬러 바 (4px): 광물별 고유 색상
  - 광물명 (16px bold #1B2556) + 영문명 (12px #666)
  - 대형 수치: 현재 비축량 (36px bold, 색상=위험도)
  - 진행바: 현재/목표 비축량
    · 배경 #E5E5E5, 채우기: 달성률에 따라 색상 변화
    · <50%: #C0392B / 50-80%: #E67E22 / >80%: #27AE60
  - 하단 3개 지표: 목표비축일수 / 현재비축일수 / 갱신일
  - 우측 하단: "조달 요청" 버튼 (Primary, h 30px)

② 전체 비축 현황 요약 바 (상단 고정)
  - 총 관리 광물 수 | 위험 광물 수(빨강) | 경계 광물 수(주황) | 정상(초록)
  - FTA 사이트 자주찾는메뉴 스타일 (아이콘 + 수치 + 레이블)

=== 탭 2: 조달 시뮬레이션 ===

[2단 레이아웃: 왼쪽 조건 설정 | 오른쪽 결과]

왼쪽: 조달 조건 설정
  ① 광물 선택 (드롭다운)
  ② 조달 수량 (숫자 input, 단위 "톤")
  ③ 조달 방식 선택 (FTA 탭 스타일)
     [긴급 현물] [장기 계약] [선물 계약] [공동 비축]
  ④ 예산 한도 (슬라이더 + 숫자)
  ⑤ 납기 요건 (달력 선택 or 드롭다운)
  ⑥ 리스크 허용 수준 (Low / Medium / High 버튼 그룹)
  [조달 시뮬레이션 실행] — Primary 버튼, 전폭

오른쪽: 시뮬레이션 결과
  ① 조달 옵션 비교 카드 3개 (자동 추천)
     - 헤더: 옵션명 + 추천 뱃지 (1순위: #1B2556 bg)
     - 단가 / 총비용 / 납기 / 리스크 점수 / 공급국
     - 선택 버튼: Primary

  ② 비용-납기-리스크 레이더 차트
     - Chart.js radar
     - 데이터: 각 조달 옵션별 3개 지표
     - 색상: #1B2556(옵션1), #007AFF(옵션2), #E67E22(옵션3)

  ③ 공급국 다변화 지수 표시
     - HHI 지수 바 차트 (낮을수록 좋음)
     - 기준선: "권고 HHI 2500 이하" 수직 점선

=== 탭 3: 의사결정 매트릭스 ===

[전체 폭 테이블]
열: 광물 | 현재비축 | 위험도 | 충격가능성 | 권고조치 | 담당자 | 진행상태 | 액션

행별 조건부 서식:
- 위험도 Critical: 행 배경 rgba(192,57,43,0.08), 위험도 셀 #C0392B bg
- 위험도 High: 행 배경 rgba(230,126,34,0.08)
- 정상: 배경 white

권고조치 컬럼: 뱃지 형태
  [긴급조달] #C0392B / [모니터링] #007AFF / [유지] #27AE60
```
