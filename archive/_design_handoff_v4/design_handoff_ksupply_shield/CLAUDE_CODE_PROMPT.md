# Claude Code 작업 프롬프트

아래는 이 핸드오프 패키지를 Claude Code에 붙여넣을 때 사용할 프롬프트 예시다.

---

`design_handoff_ksupply_shield/` 폴더에 K-Supply Shield(핵심광물 공급망 관리 플랫폼)의 프론트엔드 디자인 레퍼런스를 첨부했습니다.

- `README.md`: 전체 화면 구조, 컴포넌트 스펙, 디자인 토큰, 상태 관리 요구사항이 정리되어 있습니다. 먼저 이 파일을 읽어주세요.
- `K-Supply Shield.dc.html`: 디자인 레퍼런스(참고용 프로토타입)입니다. 이 파일은 특수 템플릿 문법으로 작성되어 그대로 실행되지 않습니다 — 마크업 구조·색상·레이아웃·인터랙션 로직만 참고하세요.
- `worldmap.html`: 세계지도 컴포넌트(d3 + topojson 기반)입니다. 순수 HTML/JS로 완결되어 있어 iframe으로 그대로 재사용하거나, 필요 시 프로젝트의 프레임워크로 이식해도 됩니다.
- `assets/`: 산업통상부 로고 파일(가로형/세로형).
- `original-design-brief.md`: 원본 기획 프롬프트(디자인 시스템 정의, 화면별 요구사항 원문).

**요청사항**:
1. 이 프로젝트의 기존 스택(프레임워크, 상태관리, 라우팅, 컴포넌트 라이브러리)을 먼저 파악해주세요. 만약 프레임워크가 아직 없다면 적합한 스택을 제안 후 진행해주세요.
2. README.md에 정리된 6개 화면(로그인 / 통합 대시보드 / 충격 시뮬레이터 / 비축·조달 의사결정 도구 / 시나리오 비교 / 정책·보고서)을 기존 코드베이스의 패턴에 맞춰 재구현해주세요. 색상·타이포그래피·레이아웃은 hi-fi 수준으로 그대로 재현하되, 컴포넌트 구현 방식(HTML 태그 등)은 프로젝트 컨벤션을 따라주세요.
3. 현재 데이터(광물 5종, 국가 7개 등)는 목업입니다 — API 연동 지점을 명확히 분리해 나중에 실 데이터로 교체하기 쉽게 만들어주세요.
4. 세계지도는 `worldmap.html`을 그대로 이식하거나, 프로젝트에서 이미 쓰는 지도 라이브러리(mapbox, d3 등)가 있다면 그것으로 대체해도 됩니다 — 다만 실제 지리 좌표 기반이어야 하며 임의로 그린 지도는 안 됩니다.
5. 작업 완료 후 각 화면의 스크린샷 또는 실행 방법을 알려주세요.
